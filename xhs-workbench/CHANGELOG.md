# 更新日志

## v0.4.0（2026-10-15）多账号、实况图与可靠性

- **多账号分别登录**：每个账号一份独立的浏览器资料，登录状态互不影响；同一账号的任务排队执行；所有网页操作前核对小红书号，不一致立即停止；「账号管理」显示登录状态
- **实况图（Live 图）笔记**：静态图 + 动态视频配对，同名文件自动配对（如 iPhone 的 HEIC + MOV）
- **多图编辑**：拖拽排序、裁剪（3:4 / 1:1 / 4:3）、删除、选择模板封面或第一张图当封面、下载全部素材
- **开机自启与防休眠**：登录电脑后自动运行工作台；有定时任务时阻止闲置休眠；同一数据目录只允许一个工作台运行
- **备份与回收站**：每天自动备份（保留 7 份）、一键恢复；删除的内容可在回收站一键恢复到原位置；数据可导出 CSV
- **知识库智能检索**：按相关度排序并高亮片段，支持「问 agent」按意思查找
- **自动化测试**：37 个测试，打包前自动运行
- 修复：重新运行连接自检不再丢失浏览器控制配置；大写扩展名（如 .HEIC）的文件名处理

## v0.3.0（2026-10-15）运营自动化

- 新增「发布排期」：7 天日历、到点提醒 + 手动发布助手、agent 自动发布；每日上限、发布间隔、错过不补发
- 新增「评论私信」：agent 抓取并起草回复，确认后发送；回复草稿违禁词检查
- 新增「数据复盘」：指标卡、每日趋势图、笔记排行、复盘报告，支持上传导出数据
- 新增定时调度：定时发布、定时检查评论、每日抓取数据；顶栏 🔔 提醒和浏览器通知
- 新增 `browser-setup`：为 Claude Code 接入 Playwright MCP 或 Claude in Chrome
- 笔记新增「可见范围」（公开 / 仅自己可见）
- 已在真实测试账号上验证：登录、抓数据、抓评论、回复评论、定时自动发布

## v0.2.0 内容生产
