# 更新日志

## v0.5.0（2026-10-15）视频笔记、对标追踪、历史导入与新手引导

- **视频笔记**：支持上传视频（mp4 / mov，最大 1GB，带上传进度），可选封面（上传图片 / 截取视频当前帧 / 模板封面 / 平台默认首帧），图文与视频一键切换（互不丢数据），素材打包包含视频；发布手册新增视频发布流程
- **对标追踪（爆款雷达）**：对标账号可开启追踪，agent 按设置的间隔检查新笔记并入库；新笔记点赞超过阈值时顶栏提醒「对标爆了」，点开详情即标记已读；没有浏览器能力时如实说明、不编造
- **历史笔记导入**：数据复盘页「导入历史笔记」，agent 把账号里已发布的笔记（标题、链接、数据）批量入库，老账号立刻有复盘数据；也支持上传导出表格
- **新手引导**：首次打开自动弹出检查清单（连接 agent → 账号定位 → 知识库 → 对标 → 第一篇笔记 → 排期发布），自动检测完成状态，每步可「让 agent 帮忙」或自己去对应页面；可跳过，概览页随时重开
- **界面图标统一**：导航、按钮、状态等结构性图标全部改为内联 SVG 线性图标（颜色跟随文字），不再依赖彩色 emoji 的跨平台渲染
- **对话面板可收起**：面板右上角加「×」，顶栏 💬 全宽度可用；宽屏收起后内容区自动占满，发消息 / 点快捷提示词会自动把面板亮出来
- 修复：从提醒点进对标详情时未清除「新笔记」角标；设置视频封面会误清视频；引导按钮文字渲染为空
- **Windows 预加固**（等真机验证）：自启动 VBS 改为带 BOM 的 UTF-16LE（中文路径不再乱码）、cmd 引号成对转义（带空格的 Node 路径可用）、取消任务用 taskkill 连浏览器等子进程一起结束、打开浏览器补齐 start 的空窗口标题参数；已知限制里记录了 Windows 上仍需真机验证的清单
- 自动化测试增至 42 个

## v0.4.0（2026-10-15）多账号、实况图与可靠性

- **多账号分别登录**：每个账号一份独立的浏览器资料，登录状态互不影响；同一账号的任务排队执行；所有网页操作前核对小红书号，不一致立即停止；「账号管理」显示登录状态
- **实况图（Live 图）笔记**：静态图 + 动态视频配对，同名文件自动配对（如 iPhone 的 HEIC + MOV）
- **多图编辑**：拖拽排序、裁剪（3:4 / 1:1 / 4:3）、删除、选择模板封面或第一张图当封面、下载全部素材
- **开机自启与防休眠**：登录电脑后自动运行工作台；有定时任务时阻止闲置休眠；同一数据目录只允许一个工作台运行
- **备份与回收站**：每天自动备份（保留 7 份）、一键恢复；删除的内容可在回收站一键恢复到原位置；数据可导出 CSV
- **知识库智能检索**：按相关度排序并高亮片段，支持「问 agent」按意思查找
- **自动化测试**：37 个测试，打包前自动运行
- 修复：重新运行连接自检不再丢失浏览器控制配置；大写扩展名（如 .HEIC）的文件名处理

## v0.3.0（2026-10-15）运营自动化

- 新增「发布排期」：7 天日历、到点提醒 + 手动发布助手、agent 自动发布；每日上限、发布间隔、错过不补发
- 新增「评论私信」：agent 抓取并起草回复，确认后发送；回复草稿违禁词检查
- 新增「数据复盘」：指标卡、每日趋势图、笔记排行、复盘报告，支持上传导出数据
- 新增定时调度：定时发布、定时检查评论、每日抓取数据；顶栏 🔔 提醒和浏览器通知
- 新增 `browser-setup`：为 Claude Code 接入 Playwright MCP 或 Claude in Chrome
- 笔记新增「可见范围」（公开 / 仅自己可见）
- 已在真实测试账号上验证：登录、抓数据、抓评论、回复评论、定时自动发布
