# 小红书运营工作台 · 安装与使用指南

一个装进 AI agent 的「小红书运营助手」。装好后，对你的 agent 说一句 **"打开小红书工作台"**，电脑上就会打开一个网页工作台。你在网页里和 agent 对话，它帮你找选题、写文案、做封面、发笔记、回评论、看数据。

> 不需要会编程。安装环境、启动服务这些技术活，都由你的 agent 自己完成。

---

## 一、你需要准备什么

1. **一台电脑**：Mac 或 Windows 都可以。
2. **一个已经装好的 AI agent**，例如：
   - Claude Code（推荐，功能最完整）
   - Codex
   - WorkBuddy、CodeBuddy、Cursor、Trae 等桌面 / 编辑器类 agent
   - Gemini CLI、Qwen Code、OpenCode 等命令行 agent
3. **小红书账号**：需要你本人登录。建议先用测试号熟悉一遍，再用正式账号。

---

## 二、安装（3 步）

### 第 1 步：解压

把下载的 `xhs-workbench-v*.zip` 解压，得到一个 `xhs-workbench` 文件夹。

### 第 2 步：放到 agent 能找到的地方

| 你用的 agent | 放到哪里 |
|---|---|
| **Claude Code** | 用户目录下的 `.claude/skills/` 文件夹中，即 `~/.claude/skills/xhs-workbench`（Windows：`C:\Users\你的用户名\.claude\skills\xhs-workbench`）。没有 `skills` 文件夹就新建一个 |
| **其他支持 skills 的 agent** | 放进它的 skills 目录（看该 agent 的说明） |
| **不确定 / 不支持 skills** | 放在任意位置都行，例如「文稿」或「文档」文件夹 |

> 找不到隐藏的 `.claude` 文件夹？也可以直接把解压出的文件夹拖进 agent 的对话框，对它说"帮我把这个技能装好"。

### 第 3 步：让 agent 打开工作台

在 agent 里发送：

```
打开小红书工作台
```

如果 agent 不认识这句话（通常是不支持 skills 的 agent），改成发送：

```
请阅读 <xhs-workbench 文件夹的位置>/SKILL.md，并按里面的说明打开小红书工作台
```

agent 会自动完成这些事：

1. 检查电脑上有没有 Node.js（工作台需要它运行），没有的话帮你安装。**安装过程中可能要你输入电脑开机密码，这一步请自己操作。**
2. 创建数据文件夹 `XHS-Workbench`（在你的用户目录下）。
3. 测试网页和 agent 之间的连接（大约 10 秒到 3 分钟）。
4. 在浏览器里打开工作台。

看到工作台页面，并且右上角显示绿色的 agent 名称，就说明安装成功了。

---

## 三、第一次使用建议

1. **跟着新手引导走**：第一次打开工作台会自动弹出引导清单，按步骤来一遍就能上手；之后可以在首页「🚀 新手引导」重新打开。
2. **完善账号信息**：左侧「账号管理」里填写账号定位、目标人群、内容风格。agent 写的所有内容都会参考这些信息。
3. **找对标**：「竞品对标」先获取候选，进入头像卡片点「补齐头像和主页数据」逐个核实。详情默认展示可见主页资料和最多 5 篇主页可见笔记；深度拆解与爆款追踪仍由 agent 完成。已写好的检查点在任务超时后也会保留。
4. **老账号导入历史数据**：「数据复盘 → 导入历史笔记」，让 agent 把已发布的笔记导入进来，复盘立刻有内容。
5. **走一遍内容流程**：选题热点 → 写成笔记（图文或视频）→ 做封面 → 发布排期。

工作台首页的「运营流水线」按顺序列出了这些步骤。

## 四、让 agent 帮你操作小红书（可选）

> 浏览器控制默认**有头 + 优先系统浏览器**（Windows 上通常是 Edge）。无头模式可能增加平台风控风险；系统浏览器和有头窗口也不能保证不受限制。

**自动发布、自动看评论、自动抓数据**都需要 agent 能控制浏览器。不开启也能用：到发布时间，工作台会提醒你手动发（会帮你复制好标题、正文，下载好封面），评论和数据也可以截图后交给 agent。

如果要开启，对 agent 说：

```
为小红书工作台开启浏览器控制
```

- agent 会先告诉你要改哪些设置，**你同意后**才会执行。
- 开启后，agent 第一次打开小红书时会停在登录页，**请你在弹出的浏览器窗口里亲自扫码登录**。工作台会保存浏览器资料；平台仍可能要求再次登录。
- agent 永远不会碰你的密码和验证码。
- **多个账号**：每个账号有自己独立的浏览器，登录状态互不影响。在「账号管理」里点「在浏览器里登录这个账号」，首次为每个号分别登录，平台可能要求再次登录。请在账号信息里填好**小红书号**——agent 每次操作前都会核对，发现登录的号不对会立即停下。

### 可选：后台有头只读采集

如果弹出的浏览器影响正常工作，可在你确认后让 agent 运行：

```bash
node xhs-workbench/scripts/workbench.mjs browser-worker-setup --yes
```

这会在本机数据目录安装可选的 `playwright-core@1.64.1`，要求先配置 **CLI + 有头 Playwright MCP**，不会改成无头；默认关闭，需在设置页开启。只读采集先在可见窗口核对本人登录的小红书号，再尝试最小化；失败时仍为可见窗口，可能抢焦点。头像来自主页头像元素的局部截图，最多只读打开 5 篇主页可见笔记；页面没显示的字段不填 0，选择器不匹配就显示原因。验证码/登录必须由你本人处理。同账号的发布/评论任务会先关闭这个工作进程，再使用原 agent 浏览器。确定性字段读取不调用模型；需要人工辨认时可选择为 Claude Code 配置快速模型，仅供建议，不能自动标记已核实。Windows Edge 的窗口焦点体验仍需真机验证。

### 账号安全，请务必了解

- 自动化操作可能不符合平台规则，**有被限流或封号的风险，请自行评估**。建议先用测试号试用。
- 默认设置都是最稳妥的：发布默认「到点提醒我」；评论回复默认「起草后等你确认」；每天最多发 3 篇，两篇之间至少间隔 60 分钟。
- 遇到验证码、"操作频繁"等提示时，agent 会立即停下来通知你。
- 想先看看效果，可以在「文案」里把笔记的可见范围设为「仅自己可见」再发布。

## 五、日常使用

| 想做的事 | 怎么做 |
|---|---|
| 打开工作台 | 对 agent 说"打开小红书工作台" |
| 关掉工作台 | 对 agent 说"关闭小红书工作台" |
| 多图 / 实况图 | 「文案」页下方的「配图」：上传、拖动排序、裁剪；同名的照片和视频（如 iPhone 导出的 HEIC + MOV）作为素材配对；不代表已完成 Live Photo 编码或小红书导入验证 |
| 视频笔记 | 「配图」区顶部切到「视频」：上传 mp4 / mov，可选封面（上传图片或截取视频画面）；发布手册对 agent 同样生效 |
| 对标卡片与主页数据 | 推荐/核实后自动接续头像、主页与最多五篇可见笔记采集，逐篇落盘；详情默认显示可见简介、指标、最多 5 篇主页可见笔记与缺失原因。未启用后台组件时用 agent，开启后也可点「改用 agent 采集」；深度拆解与追踪仍单独进行 |
| 对标追踪 | 已确认主页的对标卡片上点「📡 追踪」开启，在「追踪设置」里选检查间隔；新笔记点赞超阈值时顶栏提醒 |
| 定时发布、定时检查评论 | 在对应页面设置。**电脑需要开着，工作台需要在运行** |
| 收到提醒 | 看工作台右上角的 🔔。允许浏览器通知后，页面在后台也能收到提醒 |
| 多个账号 | 「账号管理」里添加，右上角切换。每个账号的数据和浏览器登录都分开存放 |
| 开机自动运行 | 「连接与设置 → 自动运行」勾选开机自启；防休眠选「有定时任务时保持唤醒」 |
| 备份 | 默认每天自动备份；「连接与设置 → 备份与恢复」可以立即备份、下载、恢复 |
| 找回删除的内容 | 「连接与设置 → 回收站」，点「恢复」 |
| 查知识库 | 「知识库」搜索框直接输入问题，如"怎么写标题"；想按意思找就点「问 agent」 |

> agent 任务会消耗你的 agent 额度；可选后台只读核实在字段明确时不调用模型，只有你配置快速模型且结果有歧义时才调用一次。

## 六、常见问题

**网页显示「令牌无效」或打不开**
对 agent 说"重新打开小红书工作台"。

**右上角显示「未连接 agent」**
对 agent 说"运行小红书工作台的连接自检"。

**右上角显示「等待 agent 值守」（黄色）**
你的 agent 用的是「收件箱模式」，需要它在自己的窗口里待命。对 agent 说"进入小红书工作台值守模式"，并保持 agent 窗口开着。

**找对标任务超时，页面没有全部结果**
已写完的候选/核实/主页及单篇笔记观察检查点会保留并显示在竞品对标页；刷新页面查看。列表的账号级「补齐缺失的已登记对标」可一次补齐旧条目；阻塞或重启后「整体继续」只处理未完成目标。若任务在第一条写入前就超时，不能从浏览器操作记录自动恢复数据；先核对登录状态再重试。页面若提示检查点冲突或未写完整，查看数据目录的 `accounts/<账号id>/benchmarks/checkpoints/`，不要自行把未核实的账号当成真实账号。

**头像还是空白，或笔记没有显示**
旧账号不会自动补抓头像与笔记，请逐个打开卡片点「补齐头像和主页数据」；后台组件默认关闭时会改由 agent 执行。头像无法局部截图时可手动上传（页面会标注来源）；平台页面变动、登录限制或采集超时会保留已读字段并说明原因，不能把尚未读到的内容当成真实结果。

**定时发布没有执行**
检查电脑是否休眠、工作台是否在运行。建议在「连接与设置 → 自动运行」开启开机自启和防休眠。超过计划时间 2 小时还没执行的，工作台不会补发，会标记为「已错过」，由你决定怎么处理。

**数据存在哪里？安全吗？**
所有数据都在你自己电脑的 `XHS-Workbench` 文件夹里，不会上传到任何服务器（agent 处理任务时会把相关内容发给它自己的 AI 服务，和平时用 agent 一样）。工作台只能在本机访问。删除的内容进回收站，可以在「连接与设置 → 回收站」恢复；每天的自动备份在 `XHS-Workbench/backups/`。

**实况图能在电脑上发布吗？**
取决于小红书网页版是否支持上传实况图。agent 找不到实况图上传入口时会停止发布并提醒你，这时在「发布排期」里下载全部素材，用手机 App 发布。

## 七、更新与卸载

- **更新**：先对 agent 说"关闭小红书工作台"，然后用新版本的 `xhs-workbench` 文件夹替换旧的。你的数据在 `XHS-Workbench` 文件夹里，不受影响。
- **卸载**：先在「连接与设置」里取消开机自启，关闭工作台后，删除 `xhs-workbench` 文件夹。如果也不要数据了，再删除用户目录下的 `XHS-Workbench` 文件夹（删除前请确认不再需要）。

版本变化见 [CHANGELOG.md](CHANGELOG.md)。

### 对标资料自动接续（P0）

推荐候选/核实检查点会自动进入当前账号的持久采集队列。agent 已在浏览器采集时就地写主页与逐篇笔记检查点，服务等待任务结束后判断缺项，完整目标不会再开 worker。worker 未开启时接续 agent 浏览器；能力缺失、登录/风控或部分失败会暂停并显示原因。列表支持账号级补齐、暂停、整体继续，无需逐卡点击。身份核实与资料采集状态分开。

实现与隔离验证见 [自动采集说明](../docs/benchmark-auto-collection.md)。真实创作者登录与目标主页资料已部分验证；头像、笔记全流程及 Windows Edge 焦点行为尚未通过真实验收，详见自动采集说明。

封面页新增 AI 生图区：创建任务并将交接指令发给当前具备生图能力的 Agent，完成真实 PNG 后检查结果，选择候选编辑标题。支持1–3张候选、最多3张参考图；此入口不直接调用聊天工具。

### PVT 导出与扫码保存到 iPhone

「图片创作 → 实况照片制作记录」中的已完成任务提供「下载 PVT 实况包」和「生成手机下载码」。手机与工作台连接同一 Wi-Fi，用 iPhone 相机扫码，在 Safari 下载；进入「文件 → 下载项」点击 ZIP 解压，打开 PVT，长按预览并选择“保存到照片”。无需安装接收端 App、登录 Xcode 或通过 Mac 相册中转。

二维码有效 15 分钟，可主动撤销，工作台重启后失效；Mac 需保持联网。局域网服务仅提供当前会话的下载页和配对素材包，管理服务仍只监听本机。页面显示“已提供下载”不代表系统相册已保存，手机验收结果由用户确认。

2026-10-19，用户已确认粉剂 PVT 在 iPhone 相册和小红书均识别为实况并能播放；不代表所有 iOS 版本均已验证。原图保持不变，不自动发布。旧原生接收端工程保留作历史备用，不是使用要求。
