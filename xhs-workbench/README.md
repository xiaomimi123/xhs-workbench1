# 小红书运营工作台 · 安装与使用指南

一个装进 AI agent 的「小红书运营助手」。装好后，对你的 agent 说一句 **"打开小红书工作台"**，电脑上就会打开一个网页工作台。你在网页里和 agent 对话，它帮你找选题、写文案、做封面、发笔记、回评论、看数据。

> 不需要会编程。安装环境、启动服务这些技术活，都由你的 agent 自己完成。

---

## 一、你需要准备什么

1. **一台电脑**：Mac 或 Windows 都可以。
2. **一个已经装好的 AI agent**，例如：
   - Claude Code（推荐，功能最完整）
   - Codex
   - WorkBuddy、CodeBuddy、Cursor、Trae 等桌面 / 编辑器类 agent
   - Gemini CLI、Qwen Code、OpenCode 等命令行 agent
3. **小红书账号**：需要你本人登录。建议先用测试号熟悉一遍，再用正式账号。

---

## 二、安装（3 步）

### 第 1 步：解压

把下载的 `xhs-workbench-v*.zip` 解压，得到一个 `xhs-workbench` 文件夹。

### 第 2 步：放到 agent 能找到的地方

| 你用的 agent | 放到哪里 |
|---|---|
| **Claude Code** | 用户目录下的 `.claude/skills/` 文件夹中，即 `~/.claude/skills/xhs-workbench`（Windows：`C:\Users\你的用户名\.claude\skills\xhs-workbench`）。没有 `skills` 文件夹就新建一个 |
| **其他支持 skills 的 agent** | 放进它的 skills 目录（看该 agent 的说明） |
| **不确定 / 不支持 skills** | 放在任意位置都行，例如「文稿」或「文档」文件夹 |

> 找不到隐藏的 `.claude` 文件夹？也可以直接把解压出的文件夹拖进 agent 的对话框，对它说"帮我把这个技能装好"。

### 第 3 步：让 agent 打开工作台

在 agent 里发送：

```
打开小红书工作台
```

如果 agent 不认识这句话（通常是不支持 skills 的 agent），改成发送：

```
请阅读 <xhs-workbench 文件夹的位置>/SKILL.md，并按里面的说明打开小红书工作台
```

agent 会自动完成这些事：

1. 检查电脑上有没有 Node.js（工作台需要它运行），没有的话帮你安装。**安装过程中可能要你输入电脑开机密码，这一步请自己操作。**
2. 创建数据文件夹 `XHS-Workbench`（在你的用户目录下）。
3. 测试网页和 agent 之间的连接（大约 10 秒到 3 分钟）。
4. 在浏览器里打开工作台。

看到工作台页面，并且右上角显示绿色的 agent 名称，就说明安装成功了。

---

## 三、第一次使用建议

1. **完善账号信息**：左侧「账号管理」里填写账号定位、目标人群、内容风格。agent 写的所有内容都会参考这些信息。
2. **建立账号定位**：首页点「建立账号定位」，agent 会一个个问你问题，把答案整理进知识库。
3. **找对标**：「竞品对标」里添加几个你想学习的账号，让 agent 拆解。
4. **走一遍内容流程**：选题热点 → 写成笔记 → 做封面 → 发布排期。

工作台首页的「运营流水线」按顺序列出了这些步骤。

---

## 四、让 agent 帮你操作小红书（可选）

**自动发布、自动看评论、自动抓数据**都需要 agent 能控制浏览器。不开启也能用：到发布时间，工作台会提醒你手动发（会帮你复制好标题、正文，下载好封面），评论和数据也可以截图后交给 agent。

如果要开启，对 agent 说：

```
为小红书工作台开启浏览器控制
```

- agent 会先告诉你要改哪些设置，**你同意后**才会执行。
- 开启后，agent 第一次打开小红书时会停在登录页，**请你在弹出的浏览器窗口里亲自扫码登录**。登录状态会保存下来，下次不用重新登录。
- agent 永远不会碰你的密码和验证码。

### 账号安全，请务必了解

- 自动化操作可能不符合平台规则，**有被限流或封号的风险，请自行评估**。建议先用测试号试用。
- 默认设置都是最稳妥的：发布默认「到点提醒我」；评论回复默认「起草后等你确认」；每天最多发 3 篇，两篇之间至少间隔 60 分钟。
- 遇到验证码、"操作频繁"等提示时，agent 会立即停下来通知你。
- 想先看看效果，可以在「文案」里把笔记的可见范围设为「仅自己可见」再发布。

## 五、日常使用

| 想做的事 | 怎么做 |
|---|---|
| 打开工作台 | 对 agent 说"打开小红书工作台" |
| 关掉工作台 | 对 agent 说"关闭小红书工作台" |
| 定时发布、定时检查评论 | 在对应页面设置。**电脑需要开着，工作台需要在运行** |
| 收到提醒 | 看工作台右上角的 🔔。允许浏览器通知后，页面在后台也能收到提醒 |
| 多个账号 | 「账号管理」里添加，右上角切换。每个账号的数据分开存放 |

> 每次在工作台里让 agent 做事，都会消耗你的 agent 额度（和直接在 agent 里对话一样）。

## 六、常见问题

**网页显示「令牌无效」或打不开**
对 agent 说"重新打开小红书工作台"。

**右上角显示「未连接 agent」**
对 agent 说"运行小红书工作台的连接自检"。

**右上角显示「等待 agent 值守」（黄色）**
你的 agent 用的是「收件箱模式」，需要它在自己的窗口里待命。对 agent 说"进入小红书工作台值守模式"，并保持 agent 窗口开着。

**定时发布没有执行**
检查电脑是否休眠、工作台是否在运行。超过计划时间 2 小时还没执行的，工作台不会补发，会标记为「已错过」，由你决定怎么处理。

**数据存在哪里？安全吗？**
所有数据都在你自己电脑的 `XHS-Workbench` 文件夹里，不会上传到任何服务器（agent 处理任务时会把相关内容发给它自己的 AI 服务，和平时用 agent 一样）。工作台只能在本机访问。删除的内容会先进入 `XHS-Workbench/.trash/`，可以找回。

## 七、更新与卸载

- **更新**：先对 agent 说"关闭小红书工作台"，然后用新版本的 `xhs-workbench` 文件夹替换旧的。你的数据在 `XHS-Workbench` 文件夹里，不受影响。
- **卸载**：关闭工作台后，删除 `xhs-workbench` 文件夹。如果也不要数据了，再删除用户目录下的 `XHS-Workbench` 文件夹（删除前请确认不再需要）。

版本变化见 [CHANGELOG.md](CHANGELOG.md)。
