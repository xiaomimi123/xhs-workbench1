# 浏览器与账号核对手册

所有需要操作小红书网页的任务（发布、检查评论私信、抓数据、登录）都**先**按本手册检查登录和账号，再执行各自的手册。

## 每个账号一个浏览器

- CLI 模式下启用 Playwright 浏览器控制后，**每个工作台账号都有自己的一份浏览器资料**（`browser-profiles/<账号id>/`）。你打开的浏览器自动就是当前账号的，登录状态与其他账号互不影响。
- 用 Claude in Chrome，或收件箱模式下用你自带的浏览器时，所有账号共用一个浏览器。这时更要严格执行下面的「账号核对」。

## 登录检查

1. 打开 `https://creator.xiaohongshu.com/`。
2. 出现登录页时：**停下**，在回复中请用户在打开的浏览器窗口里亲自登录（扫码或验证码由用户本人完成）。每 15 秒检查一次，最多等 5 分钟；超时则结束任务并说明。
3. 登录后读取页面上的**昵称和小红书号**。
4. 写入当前账号数据目录下的 `browser.json`：

```json
{ "loggedIn": true, "nickname": "昵称", "xhsId": "小红书号", "checkedAt": "2026-10-15T10:00:00.000Z" }
```

没登录上就写 `"loggedIn": false`。

## 账号核对（每次操作前都要做）

用登录检查读到的小红书号，和提示词「当前账号」中的小红书号比较：

| 情况 | 处理 |
|---|---|
| 一致 | 继续执行 |
| 当前账号没有填写小红书号 | 继续执行，并在回复中提醒用户：到「账号管理」里补上小红书号（填写后才能防止用错号） |
| **不一致** | **立即停止，不做任何操作**。在回复中说明：浏览器登录的是哪个号、当前账号应该是哪个号。发布任务按 `publish.md` 标记为 `failed` |

## 其他

- 每次任务结束，浏览器会随之关闭；登录状态保存在浏览器资料里，下次不用重新登录。
- 截图、页面快照等临时文件只放在工作台指定的输出目录，不要写到数据目录其他位置。
