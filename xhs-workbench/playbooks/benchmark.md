# 竞品对标操作手册

目标：找到值得学习的账号，拆出它们**可复制的规律**，变成我方的选题和方法论。

## 数据位置（当前账号数据目录下）

```
benchmarks/
├── index.json                 对标账号列表
└── <对标id>/
    ├── report.md              拆解报告（Markdown）
    ├── notes.json             采集到的笔记数据
    └── screenshots/           用户上传的截图（只读，可分析）
```

### index.json

```json
{
  "items": [
    {
      "id": "b_xxx",
      "name": "账号名",
      "xhsId": "小红书号",
      "url": "主页链接",
      "followers": "12.3万",
      "positioning": "一句话定位",
      "remark": "用户备注",
      "status": "pending | analyzing | analyzed",
      "analyzedAt": "2026-10-15T10:00:00.000Z",
      "summary": "一句话总结最值得学的点（显示在卡片上）"
    }
  ]
}
```

- 新增对标账号：`id` 用 `b_` + 任意字母数字（如 `b_20261015a`），`status` 填 `pending`。
- 修改时保留其他字段，只改需要的字段；不要删除条目（用户可以在界面删除）。

### notes.json

数组，每篇笔记一项，至少采集互动量前 10 的笔记：

```json
[
  {
    "title": "笔记标题",
    "url": "笔记链接",
    "type": "图文 | 视频",
    "likes": "1.2万",
    "collects": "8000",
    "comments": "320",
    "publishedAt": "2026-09-01",
    "coverText": "封面上的文字",
    "topicType": "选题类型，如 清单/教程/测评/避坑/经验分享",
    "titlePattern": "标题套路，如 数字+痛点、反常识"
  }
]
```

## 拆解步骤

1. 把 `index.json` 中该账号的 `status` 改为 `analyzing`（界面上点「拆解」时已自动改好）。
2. 收集信息，按能力从高到低选择方式：
   - 能控制浏览器：打开账号主页，按互动量浏览笔记（遵守 `README.md` 的账号安全规则，慢速浏览，不点赞不评论不关注）。
   - 能搜索网页：搜索账号名和代表作，收集公开信息。
   - 都不能：读取 `screenshots/` 里用户上传的截图；截图不够时，在回复里告诉用户需要截哪些页面。
3. 写 `notes.json`。
4. 写 `report.md`，结构如下：

```markdown
# 对标拆解：@账号名

> 一句话结论：最值得学的是……

## 账号画像
定位、目标人群、人设、更新频率、变现方式

## 爆款规律
### 选题
### 标题
### 封面
### 正文结构
### 评论区运营

## 数据观察
互动最高的几类内容，以及可能的原因

## 我们可以借鉴的 5 件事
1. 具体、可执行的动作……

## 不建议照搬的地方
```

5. 更新 `index.json`：`status` 改 `analyzed`，写 `analyzedAt` 和 `summary`，补上 `followers`、`positioning` 等字段。
6. 回复用户：3-5 条最重要的发现，并建议下一步（生成选题 / 沉淀知识库）。

## 推荐对标账号

根据账号定位（见提示词中的「当前账号」和知识库 `账号定位/`），推荐**同赛道、粉丝量级略高于我方、近期仍在更新**的账号，每个说明推荐理由，登记到 `index.json`。拿不到真实数据时如实说明，不要编造粉丝数和链接。

## 原则

- 只学规律，不抄内容；报告中不要大段复制对方原文。
- 数据拿不到就留空，不要编造。
