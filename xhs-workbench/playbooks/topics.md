# 选题操作手册

目标：持续产出**有流量、契合账号、我们写得出来**的选题，放进选题池供用户挑选。

## 数据位置

当前账号数据目录下 `topics/topics.json`：

```json
{
  "items": [
    {
      "id": "t_xxx",
      "title": "选题（一句话说清楚写什么）",
      "angle": "切入角度：和别人有什么不同",
      "keywords": ["搜索关键词1", "关键词2"],
      "source": "热点 | 对标拆解 | 知识库 | 评论区 | 用户",
      "sourceRef": "来源细节，如对标 id、热点名称",
      "scores": { "heat": 80, "fit": 90, "competition": 60, "ease": 85 },
      "score": 81,
      "reason": "一句话说明为什么值得做",
      "status": "idea",
      "noteId": null,
      "createdAt": "2026-10-15T10:00:00.000Z"
    }
  ]
}
```

- 新选题追加到 `items` **开头**，`id` 用 `t_` + 任意字母数字，`status` 填 `idea`。
- 不要修改或删除已有选题（状态由用户在界面维护），除非用户明确要求。
- 写入前检查是否已有相同或高度相似的选题，避免重复。

## 打分规则（每项 0-100）

| 维度 | 含义 |
|---|---|
| heat 热度 | 近期搜索 / 讨论热度，季节和节日相关性 |
| fit 契合度 | 和账号定位、目标人群的匹配程度 |
| competition 竞争空间 | 同类内容越少、越有新角度，分越高 |
| ease 易产出 | 我们手上有素材、能快速写好的程度 |

`score` = heat × 0.3 + fit × 0.35 + competition × 0.15 + ease × 0.2，取整。

## 生成步骤

1. 读账号定位（提示词中的「当前账号」+ 知识库 `账号定位/`）、知识库 `爆款方法论/`、`复盘结论/`。
2. 收集选题来源，能做到哪步做哪步：
   - 能搜索网页 / 控制浏览器：查小红书搜索下拉词、热门话题、节日节点、行业新闻。
   - 已有对标拆解：读 `benchmarks/*/report.md` 中的爆款规律。
   - 都没有：基于知识库和常识生成，并在 `reason` 里注明"未核实实时热度"。
3. 每个选题写清 `angle`，避免"泛泛而谈"的选题（"减脂餐推荐"→"打工人 15 分钟减脂便当，一周不重样"）。
4. 打分、写入文件。
5. 回复用户：列出得分最高的 3-5 个，并说明理由。

## 选题被选中写成笔记时

界面会创建笔记并把选题 `status` 改为 `writing`、写入 `noteId`。写作按 `copywriting.md` 进行。
