# 素材库操作手册

素材库（`materials/`）是用户收藏的**参考素材**：剪辑里值得学习模仿的片段、封面截图、效果好的文稿。你的提示词里会自动带上素材清单（卡片 + 标签 + 批注）——写文案、做封面、出脚本前，把素材批注当作用户的「模仿要求」来读。

## 数据位置

```
materials/
├── index.json      素材卡片（标题 / 类型 / 标签 / 批注 / 来源）
└── files/          素材文件本体（视频 mp4/mov/webm、图片 png/jpg/webp/gif/heic、文稿 srt/txt/md）
```

### index.json 条目

```json
{
  "id": "m_xxx",
  "title": "开头 3 秒钩子范本",
  "type": "video | image | script",
  "file": "hook-cut.mp4",
  "tags": ["开头钩子", "实拍"],
  "note": "前 3 秒直接给结果不给过程，留一个悬念",
  "source": "@某账号 10-12 的爆款",
  "createdAt": "…",
  "updatedAt": "…"
}
```

- `note` 是用户手写的批注，**是素材的灵魂**：写内容时优先照着批注模仿。
- 修改时保留其他字段；不要删除条目（用户在界面删除，会进回收站）。

## 怎么「学习」素材

1. **看卡片就够时**（写文案、想结构）：提示词里已带卡片信息，直接按批注模仿，不用打开文件。
2. **需要看本体时**（拆节奏、看转场、抠字幕样式）：
   - 视频：用抽帧能力每隔 2–3 秒截一帧看画面变化，配合 srt / 口播稿理解节奏；注意开头 3 秒和结尾。
   - 图片：直接读图，看排版、字体层级、强调方式。
   - 文稿：直接阅读，学句式和钩子写法。
3. **沉淀规律**：把学到的手法按 `knowledge.md` 写进知识库 `爆款方法论/`（写明「来自素材库：xxx」），用户点了「让 agent 学习这条 / 提炼全部规律」时必须做这一步。

## 怎么往素材库加东西

用户口述或你建议收藏某条参考时，按上面的格式登记（文件让用户提供，或你下载/生成后放进 `materials/files/`）。批注（`note`）尽量引导用户自己写——那是用户的审美判断，比你的总结更有指导性。

## 原则

- 素材是「用户的审美样本」，模仿批注，不要只凭自己的感觉。
- 学规律进知识库，素材本体不动、不重命名、不删除。
