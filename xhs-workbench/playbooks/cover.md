# 封面操作手册

工作台内置 4 个封面模板，用 Canvas 渲染成 1080×1440（3:4）PNG。**你不需要自己画图**：把封面规格写进笔记的 `meta.json`，工作台会自动渲染并保存为 `cover.png`（需要用户的工作台网页开着；没开时下次打开会补渲染）。

## 封面规格（spec）

```json
{
  "template": "bigtext | photo | list | memo",
  "palette": "red | cream | mint | sakura | blue | night",
  "title": "封面主标题\n用换行控制断句",
  "emphasis": ["要高亮的词"],
  "subtitle": "副标题（可选）",
  "badge": "角标，如 干货 / 第3期（可选）",
  "items": ["清单要点1", "要点2"],
  "image": "images/ 目录下的文件名（photo 模板用）"
}
```

| 模板 | 适合 | 说明 |
|---|---|---|
| `bigtext` 大字报 | 观点、干货、结论前置 | 渐变底色 + 超大标题 |
| `photo` 图片大字 | 有好看的实拍图 | 背景图 + 底部渐变 + 白色大字，需 `image` |
| `list` 清单 | 合集、步骤、避坑清单 | 标题 + 最多 6 条编号要点（`items`） |
| `memo` 便签 | 经验分享、生活感 | 笔记本纸 + 荧光笔强调 `emphasis` |

配色：`red` 小红、`cream` 奶油、`mint` 薄荷、`sakura` 樱花、`blue` 雾蓝、`night` 深夜。

## 写法

- **给方案**：用户要"出几个封面方案"时，把多个 spec 写进 `meta.json` 的 `coverOptions` 数组，用户在界面上点选套用。方案之间要有差异（模板 / 配色 / 文案角度不同）。
- **直接定稿**：用户要求直接做封面时，写进 `meta.json` 的 `cover`。
- 修改 meta.json 时保留其他字段。

## 封面文案原则

- 封面标题 ≤ 15 字最佳，可以和笔记标题不同：更短、更有冲击力。
- 用 `\n` 手动断句，每行是一个完整的意思，避免一个词被拆到两行。
- `emphasis` 选 1-2 个最抓眼球的词（数字、结果、痛点）。
- 先查知识库 `爆款方法论/`、`对标拆解/` 里关于封面的规律。

## 配图

- 用户需要配图时：如果你有生图 / 找图能力，把图片保存到笔记的 `images/` 目录（png / jpg），再在封面 spec 的 `image` 填文件名。
- 没有生图能力：如实告诉用户，建议用户上传实拍图（封面面板「上传图片」）。
- 不使用来源不明、可能侵权的图片。
