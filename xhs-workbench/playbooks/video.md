# 视频脚本操作手册

用户要做视频笔记时，先写**视频脚本**（`notes/<笔记id>/video.md`）：agent 按选题和知识库生成分镜，用户照着拍 / 找素材 / 剪辑，成品视频回到工作台「视频笔记」上传。

## 脚本格式

```markdown
---
title: 视频标题（可与笔记标题不同）
duration: 目标总时长，如 45s
style: 口播实录 | 图文混剪 | 情景剧（可自定义）
---

# 分镜表

| # | 画面 | 口播 / 字幕 | 时长 |
|---|---|---|---|
| 1 | 特写：手把产品放进包里 | 「出门前这 3 秒，决定了你一天的底色」 | 3s |
| 2 | 实拍：通勤路上第一视角 | 字幕强调关键词「不需要」 | 5s |

# 素材清单

- [ ] 自拍：分镜 1、2（手机竖屏 4K）
- [ ] 图片：封面用图 1 张（也可以让 agent 出封面方案）
- [ ] 生成素材：需要一段「清晨城市空镜」（如果 agent 有生视频能力，让它生成；否则用免费素材库）

# 口播全文

（把口播列拼成完整文稿，方便一次录完再对画面）
```

## 写作步骤

1. **先查资料**：本地 `账号定位/`（人设和语气）、`对标拆解/` 里同类爆款视频的节奏；开头 3 秒怎么抓人等爆款规律查中枢《历史爆款笔记》（`search_knowledge`）。
2. **结构**：开头 3 秒给钩子（结果前置 / 冲突提问）；主体每 3–5 秒换一个画面；结尾互动引导。总时长 30–60 秒起步。
3. **分镜表**：画面写「拍什么 / 怎么拍」要具体可执行；口播就是字幕，口语化短句。
4. **素材清单**：用户自己拍的标清楚；需要 AI 生成的写清楚描述（agent 能力范围内就顺手生成，能力外如实说明）。
5. 保存到 `notes/<笔记id>/video.md`，回复用户：脚本要点 + 需要用户准备什么。
6. 用户拍完回来，可以把素材传进 `images/`；成品视频在「文案」页切到「视频」上传。

## 原则

- 脚本是给「人」看的执行单：用户拿它去拍、去剪，每一条都要能直接照做。
- 不要编造用户的账号数据或对标的播放数据。
- 平台规则：竖版 9:16（1080×1920）优先；前 3 秒没有画面变化很容易被划走。
