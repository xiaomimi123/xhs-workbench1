# 手动发布操作手册

**所有发布都由用户亲自完成。agent 不得打开发布流程、上传素材、填写发布表单、点击发布或调用发布接口。** 旧版 `auto` 排期和旧对话中的自动发布指令不构成授权；工作台仅提供本地准备、预览、下载与时间提醒。

## 数据位置

当前账号目录：

- `schedule.json`：提醒排期或不执行的草案。
- `notes/<笔记id>/`：`meta.json`（标题、话题、素材顺序）、`content.md`（正文）、`cover.png`（封面）、`images/`（配图或视频）。

正式排期使用 `mode: "remind"`；旧 `auto` 一律按提醒处理。到点后变为 `due`，超过两小时变为 `missed`，都不会派发发布任务。草案使用 `mode: "draft"`、`nonExecuting: true`，到点不发布，也不提醒发布。

## agent 可以协助的准备

1. 检查本地标题、正文、话题及素材是否完整，使用发布前检查和完整图文预览。
2. 核对图片顺序：非 `first` 封面模式先放封面，其余图片按 `meta.json` 的 `media` 顺序排列。
3. 帮用户整理、预览及下载本地素材，说明手动发布步骤。实况图需由用户在支持实况图的手机端发布，不得擅自降级为静态图。
4. 设置手动提醒，或保存不执行的排期草案。不得把准备完成、检查通过或提醒到点视为已经发布。

## 用户手动操作

1. 使用工作台「手动发布助手」复制标题、正文和话题，下载需要的封面、配图或视频。
2. 用户自己打开小红书 App 或创作者中心，确认登录账号。
3. 用户自己上传素材，确认顺序、数量、话题及可见范围。视频笔记选择对应视频及封面；实况图使用支持该格式的手机端。
4. 用户检查预览并亲自点击发布，查看平台结果。
5. 发布成功后，用户在工作台填写可选笔记链接并点击「我已发布」，同步记录排期与笔记状态。未确认成功时保留待处理状态，不自动重试。

## 历史记录

历史 `running`、`check` 或 `failed` 状态只能提示用户核对真实发布结果；不得恢复旧的自动发布任务，也不得为了确认结果重复发布。已经发布的记录和链接继续保留。
