# 知识库使用说明

这里放的是**你这个账号自己的笔记**：账号定位、对标拆解、复盘结论、账号经验、素材。agent 做选题、写文案、回复评论前会先来看，**沉淀得越多，产出越像你的账号**。

## 公司口径在中枢，不在这里

品牌调性与人设、产品卖点、违禁词与广告法、爆款规律、售后话术……这些「公司说了算」的内容放在**企业中枢的知识库**里，由主管维护、审核。agent 会用中枢工具去查，**两边不一致时以中枢为准**。

所以这里不再放「品牌口径」「爆款方法论」。以前建过这两个目录的，里面的文档保留着可以参考，但公司口径以中枢为准；有价值的内容可以让 agent 整理后提交给中枢（由主管审核）。

## 怎么用

- **口述给 agent**：在右侧对话框说「帮我把这条经验存到知识库：……」，agent 会整理成规范文档。
- **自己写**：点「新建文档」，用 Markdown 编写。
- **让 agent 整理**：打开任意文档，点「让 agent 处理」，比如让它补充、改写、合并。

## 目录

- **账号定位**：每个账号做什么、给谁看、什么人设
- **对标拆解**：对标账号的拆解报告
- **复盘结论**：数据复盘得到的经验（值得全公司共享的，经你确认后提交给中枢）
- **账号经验**：只适用于你这个账号的做法和心得
- **素材库**：金句、案例、可复用段落

模板文档可以直接修改，也可以删除。
