# 知识库使用说明

这里沉淀你做小红书的所有经验。agent 在选题、写文案、回复评论之前会先来这里查资料，**沉淀得越多，产出越像你**。

## 怎么用

- **口述给 agent**：在右侧对话框说「帮我把这条经验存到知识库：……」，agent 会整理成规范文档。
- **自己写**：点「新建文档」，用 Markdown 编写。
- **让 agent 整理**：打开任意文档，点「让 agent 处理」，比如让它补充、改写、合并。

## 目录

- **账号定位**：每个账号做什么、给谁看、什么人设
- **品牌口径**：卖点、标准话术、禁用说法
- **爆款方法论**：标题、封面、正文的规律
- **对标拆解**：对标账号的拆解报告
- **复盘结论**：数据复盘得到的经验
- **素材库**：金句、案例、可复用段落

模板文档可以直接修改，也可以删除。
