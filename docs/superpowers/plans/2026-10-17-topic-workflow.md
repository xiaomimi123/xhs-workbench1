# 选题热点接续 Implementation Plan

**Goal:** 将已采集对标证据用于选题生成，保留来源与分析状态，可靠地从选题生成单份草稿。

**Architecture:** 新增 topic-workflow.mjs 管理账号隔离的持久任务和冻结输入。复用现有 Bridge agent，但 agent 只写指定结果文件，由服务端校验后合并正式选题/稿件。SSE 显示排队、运行、完成、错误及重试。只读已采集材料，不重新抓网页，不自动发布。

- [x] 来源与任务：区分 observed/analyzed，保留 URL、观察时间、对标 id。未核实热度不伪造评分；冻结输入供审计。
- [x] 可靠草稿：同一选题复用关联稿；失败重试复用稿件；服务重启标记中断；检测用户编辑冲突，不覆盖。
- [x] 接口和界面：选择已采集对标生成 3 个选题、来源链接、待评估标记、任务状态和重试；写成笔记通过服务端任务接口。
- [x] 验证：隔离测试覆盖重复请求、伪造来源、无产出、失败重试、重启、跨账号和编辑冲突；真实「小互」生成选题并选一个写成草稿，记录真实 agent 结果及局限。

用户已批准上述范围并要求实施；不再次请求设计确认。保留现有工作树与各模块功能。
