# 参考视频复刻实施计划

已获用户批准：在现有视频创作中添加 v2v、rv2v、根据参考生成与优化动作描述。沿用当前工作区，保留所有已有修改与素材，不提交付费生成，不发布。

架构：独立 VideoReferences 管理账号内视频（最多60,000,000字节，真实容器校验），VideoDescriptionWorkflow 通过现有 Agent bridge 分析带时间点的抽帧，结果由用户应用；VideoWorkflow 冻结视频并发送 source_video。

- [x] 先编写失败测试：两种模式、源视频必填与账号隔离、篡改检查、请求快照、Agent结果校验及恢复、UI显式应用与无自动生成。
- [x] video-references.mjs：上传/查询/读取，ffprobe校验MP4/MOV/WebM/MKV/AVI，最大120秒，抽取12张时间标记帧，不处理音频；拒绝软链接/非法ID。
- [x] video-service.mjs / video-browser-transport.mjs / video-workflow.mjs：扩展模式、校验图片数、将 source_video 冻结、哈希去重、一次提交、原有下载流程。
- [x] video-description-workflow.mjs / server.mjs：输入快照、Agent任务、状态事件、结果字段验证、GET任务列表/POST创建，重启中断有明确错误；禁止自动提交视频。
- [x] video-creation.js：参考复刻入口、视频上传/预览/选择，描述助手和候选应用，原描述历史、任务进度和参考对照；响应式样式。
- [x] 隔离文件和模拟服务端端到端验证，测试边界及原功能回归；无在途任务时重启工作台，验证入口。

验收：真实用户参考视频尚未提供，不能声称复刻质量验证通过。测试不访问小红书、不调用付费视频生成接口。

## 已实现与验证（2026-10-20）

- 上传保留原视频，校验实际容器/视频轨/120秒时长/60MB大小；按账号隔离、内容哈希去重、提交时再次检查源文件。
- v2v 与 rv2v 在直连和浏览器兼容连接中均已开放，提交冻结 source_video；延用已知远端任务查询/下载，不重试不确定的生成提交。
- 描述助手使用12张时间标记帧，交由已连接 CLI Agent 处理；候选显式应用，原描述保存在输入快照，页面可恢复上一版。没有音频分析。
- 描述任务使用独立本地文件适配器，不挂载工作台的浏览器资料、不恢复浏览器会话、不解除平台访问锁。目前支持 Codex CLI 和 Claude Code。
- `node --test tests/bridge.test.mjs tests/server.test.mjs tests/video-*.test.mjs`：58项通过，包括真实HTTP上传/抽帧/假Agent回调、模式参数与请求体、源视频快照与下载、账号隔离、平台锁不变、候选应用/恢复。
- Ego 浏览器检查实际工作台的 v2v / rv2v 入口和控件；390/768/1280 宽度无表单横向溢出。截图接口超时，未获得视觉截图，不将DOM尺寸检查称为视觉截图验收。
- 真实 Codex 在独立临时工作区使用2秒测试图案：根据参考生成描述、优化现有描述均成功，各返回12项观察；没有调用视频生成API，也未导入用户账号资料。
- 待用户提供实际参考视频后再验证 v2v/rv2v 生成效果、产品一致性与动作相似度。本轮不验证声画复刻，不发布。
