# 数据复盘：已有数据到下一轮选题

本轮设计已获用户确认并实施。目标是接通已保存的数据、受控复盘报告与下一轮选题，不发布、不发送消息、不重新抓取外部平台。

## 现状与数据边界

现有 analytics 页有指标、趋势、排行和 Markdown 报告，但生成复盘依赖通用 agent 对话直接写正式文件，缺少结构化任务及回流选题入口。缺失或无效指标会被 num() 转为 0，可能误导汇总与互动率。已有账号数据截至 2026-10-16，不能称为实时数据。

小互已有五篇真实页面采集的对标笔记与公开互动数字，属于对标观察。由其生成的 n_mvc84cl5e37068 仍是未发布草稿，没有发布效果数据。两类数据分开呈现，不能合并为本账号业绩，也不能给未发布草稿编造阅读、互动或涨粉。

## 方案选择

推荐先做已有数据复盘闭环：结构化报告与选题回流，可直接用已有数据验收。仅优化图表无法接通选题；先扩展实时平台采集需要登录及外部页面验证，增加本轮依赖，留后续。

## 本轮功能

1. 数据质量：显示来源类型、观察时间、样本数量、缺失指标及关联笔记。缺失/无效值显示未知，真实 0 保留。互动率只有阅读大于零且点赞、收藏、评论均已知才计算。累计快照与每日新增分开；不足以形成趋势时明确说明。部分覆盖的合计展示覆盖数量，不当完整总量。
2. 受控复盘：选择本账号已有数据或指定对标资料，冻结输入快照；Agent 只写暂存结构化结果，服务端校验后保存报告。报告含数据概览、证据引用、观察结论、待验证假设、下一步实验和选题建议。输入文字是资料，不是指令；不保证因果关系，不声称未知热度已验证。
3. 任务状态：排队、处理中、完成、失败、重试；防重复，重启中断可恢复重试；按账号隔离，切页或切账号后旧响应不能覆盖当前页。
4. 回流选题：用户点击某条建议加入选题池，保留报告 ID、数据来源、观察时间和证据。重复点击复用同一条选题；通过现有写稿流程生成新草稿，保留原有小互草稿与素材。
5. 原有数据文件、历史报告、抓取和导入功能保留。本轮不新增文件解析器、外部采集、自动发布或自动改写原稿。

## 验收

隔离测试覆盖缺失与 0、数值格式、缺少分母/分子、部分覆盖、来源分隔、无效证据、账号隔离、任务失败/重试/重启、重复选题及页面竞态。

真实工作台使用已有账号数据核对展示与来源；用小互五篇已采集资料生成明确标注为“对标观察复盘”的报告，从一条建议加入选题池并写成新的验证草稿。新报告、选题和新草稿保留供检查，原有小互文案、素材与取消的排期记录保持不变。前后核对原笔记文件摘要。验证报告明确区分本地真实 agent 工作流、历史数据与本轮未验证的外部平台数据。
