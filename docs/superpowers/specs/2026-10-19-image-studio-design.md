# 封面生图与参考图生成

用户确认先升级封面，优先使用当前 Agent 生图能力；后续目标为小红书可发布 Live Photo 和视频。现有封面仅模板排版，当前工作台桥接 Claude Code CLI，本聊天生图工具不能由网页直接调用。

本轮采用明确的当前会话交接：用户在封面页填写提示词、选择最多三张笔记图片作参考、选择生成1–3张，保存任务后可复制完整交接指令。Agent 读取冻结输入，调用真实生图工具，将 PNG 输出放入任务暂存目录，写结果清单；工作台校验实际图片后显示候选。网页可“检查生成结果”，Agent 也可调用相同完成接口。无能力时明确失败，不用模板或程序绘图冒充生图。

任务与笔记、账号绑定。参考图复制冻结，记录哈希；输出只接受任务目录内普通 PNG，校验像素与尺寸、输入指纹，拒绝软链接及路径穿越。输出验证完再进入候选；生成失败可重新建任务，不能无感重复付费执行。相同请求复用任务，明确“新一轮生成”才新建。

候选底图与封面文字层分开：选中候选加入笔记图片，使用现有 photo 模板可编辑标题，显式保存封面，保留旧图备份。未选候选不占笔记配图位置。保留原稿和素材，生成不发布。文案改变则任务显示过期且禁止应用，历史候选仍可查看。

本轮不制作 Live Photo 或视频。候选记录 parentAsset/referenceHashes、尺寸、提示词与生成方式，后续供动态图与视频引用。Live Photo 必须在后续单独验证照片/视频配对、相册识别与小红书导入，不能将普通 MP4 标为 Live Photo。

验收：隔离测试覆盖真实 PNG、非法输出、参考冻结、跨账号、过期、重复应用；实际 Codex 生图及参考图生成分别产出图片，在工作台验证候选、套用、可编辑标题和保存预览。无外部平台发布。
