# 图片创作统一工作区

用户已确认：原封面配图升级为图片创作，三个入口为自由生图、参考图复刻、根据文案配图。自由生图与复刻不必先创建笔记。保留现有封面编辑器，图片创作与模板排版共用素材。

输入包括画面描述、可选精确标题、风格分类（腐乳食欲特写/粉剂暖光场景/咖啡生活随拍）、1–3张候选、参考图角色（风格/产品）。完整海报把文字生成进图，须明确文字不能直接作为图层编辑；底图模式无标题，套入既有封面编辑器后再排文字。产品参考要求尽量保持外观，但不能把生成结果当作包装准确性的保证。

参考图与任务在账号目录独立保存。既有带noteId的任务兼容；无noteId的任务也能完成、预览和下载，关联笔记时显式选择目标。原稿不自动更改；完整海报设为封面采用第一张图片模式，原模板封面文件保留；底图导入后进入文字编辑器。添加配图和保存共享素材库均幂等。跨账号、已发布/视频目标、过期关联稿、候选被修改均拒绝。

当前仍为Agent交接，不承诺网页自动调用聊天生图工具。用当前会话imagegen根据粉剂参考真实生成完整海报，再回填工作台校验。Live Photo与视频留待后续。
