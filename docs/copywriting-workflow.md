# 文案：改写、标题优化与内容检查

文案页现在直接处理选题生成的草稿，并显示选题关联和对标来源。

- 改写：填写要求后点击「让 agent 改写」，仅回填正文和话题。原标题、来源和其他资料保留。
- 标题优化：点击「生成标题备选」，生成五个标题及对应理由；点击候选选择正式标题，保存或继续检查。
- 内容检查：点击「让 agent 深度检查」，保存并展示摘要、对应原文、修改建议、待核实事项和规则检查结果。检查不直接修改稿件。修改正文、标题或标签后报告会提示过期，未保存的编辑也会提示。

各操作保存原稿输入快照，显示排队、处理中、完成或错误状态；失败支持重试。服务中断后任务可恢复重试。同一篇笔记同一时刻只执行一个文案任务。任务期间手动编辑不会被异步页面刷新覆盖，正式稿件发生变化则拒绝回填旧结果。快照位于账号目录 `copy-jobs/*.input.json`。
