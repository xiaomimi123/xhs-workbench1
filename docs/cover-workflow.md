# 封面配图：草稿到完整图文预览

从文案页「做封面」进入对应笔记，点击「让 agent 出 3 个方案」。选择方案后保存封面；点击「生成三张内容卡片」生成内容配图。卡片采用模板排版，不是 AI 插画或照片生成。

工作台网页打开时负责渲染 PNG。任务区分设计中、方案已生成、待渲染、PNG 已保存与失败；未落盘不显示图片完成。重新打开网页可继续待渲染任务，渲染失败有重试入口。点击卡片可修改标题、要点、强调词和配色，再保存；已有卡片被修改前备份旧 PNG。保存已有封面也会备份旧图及封面规格。

新图片追加到现有素材顺序，重复请求不重复添加。页面下方可调整图片顺序。点击「完整图文预览」逐张查看实际保存的封面和配图，连同标题、正文和标签。生成和保存不会修改文案或自动发布。

任务按账号隔离，文案变化会使旧方案过期，旧任务不能覆盖当前稿件。封面保存会检查当前文案、封面规格和封面使用模式，异步刷新不会覆盖正在输入的内容或切换后的页面。原稿快照保存在账号目录的 `cover-jobs/*.input.json`；被替换图片的备份在笔记目录 `cover-backups/`。

## AI 生图与参考图生成（2026-10-19 升级）

封面页新增独立生图区，支持文字描述或选择最多三张参考图，生成1–3张候选。原有模板与内容卡片继续可用。

当前采用 **Agent 会话交接**：创建任务→复制交接指令给具备生图工具的 Agent→Agent 读取冻结输入并生成实际 PNG→检查生成结果→套用底图→编辑标题→保存封面。工作台目前连接的 Claude Code CLI 和本次 Codex 会话不是同一个工具环境；网页按钮不能自动调用本会话内置生图。任务不会暗中改成 API 调用，也不会以模板绘图冒充生图。

参考图上传后保存在笔记图片中；创建任务时另复制到任务快照目录。生成候选在 `image-jobs/<任务>/candidates/`，未选中前不加入笔记配图。选中才导入，重复选中不重复增加。底图与中文标题分别保存，修改标题不需要重新生图。原封面替换沿用旧图备份。

任务保存提示词、参考图指纹、尺寸、生成方式及父素材信息。文案变更时禁止直接应用旧任务，要求基于新稿重新生成。没有输出、无效图片、软链接、路径穿越或快照变更均不会显示完成。

后续 Live Photo/视频将从这些实际素材接入。本轮不把普通 PNG/MP4 标为 Live Photo，也没有执行小红书发布；实况照片的配对、手机相册识别与小红书导入需下一阶段单独验收。

### 图片创作统一入口（2026-10-19）

导航「图片创作」提供自由生图、参考图复刻、根据文案配图。前两项无需先创建笔记；文案中的「生成图片」自动带入当前草稿。选择完整海报可生成含标题的成品，选择底图则在关联笔记后进入原封面编辑器排文字。风格参考与产品主体单独标记，任务会冻结图片、标题、要求和角色。

当前 Agent 模式通过任务指令交接：网页创建任务 → 把指令交给具备生图能力的 Agent → 生成真实 PNG 并写 result.json → 检查生成结果。网页不自动调用 Codex 聊天生图工具。候选可预览、下载、保存共享素材库、添加到指定草稿，完整海报可设为首图封面。原文案和旧封面文件保留，所有动作均不发布。Live Photo 和视频制作尚未接入此流程。

### Live Photo（2026-10-19）

已完成候选提供「制作实况照片」，自动冻结原图，制作三秒无声轻微推近回位，保留原稿和候选。该版本采用 macOS CoreImage/AVFoundation，不重绘文字或商品，不是AI生成主体运动。依赖 Apple Swift 编译工具链；初次制作编译本地工具，后续缓存复用。不支持的平台或渲染校验失败会明确报错。

生成独立 JPEG、配对 MOV、网页 MP4 预览。JPEG MakerApple 17 与 MOV content.identifier 相同；MOV 定时 still-image-time=1.5 秒，静态帧对应中点。写完后重新读取元数据并检查 PHLivePhoto 能否加载，输出哈希用于下载和人工验收前校验。网页预览不是实况识别的替代证据。

ZIP 内 LIVE.JPG＋LIVE.MOV 必须成对导入 Mac 照片，再从照片通过 AirDrop 或已启用的 iCloud 照片到 iPhone。用户确认 iPhone LIVE 和播放、小红书编辑页实况识别后，才在工作台记录人工验收；可撤回，不发布。单独下载 JPG/MP4 或改文件后缀不能生成实况。手机端未验收时状态保持待实测，不声称“小红书验证通过”。

文件损坏时任务标记失败并允许重制；服务重启把未结束任务标记中断。ZIP 下载失败返回错误，不结束工作台进程。实况素材暂不追加普通图文图片列表，也不进入发布队列。
