# 封面配图：草稿到完整图文预览

从文案页「做封面」进入对应笔记，点击「让 agent 出 3 个方案」。选择方案后保存封面；点击「生成三张内容卡片」生成内容配图。卡片采用模板排版，不是 AI 插画或照片生成。

工作台网页打开时负责渲染 PNG。任务区分设计中、方案已生成、待渲染、PNG 已保存与失败；未落盘不显示图片完成。重新打开网页可继续待渲染任务，渲染失败有重试入口。点击卡片可修改标题、要点、强调词和配色，再保存；已有卡片被修改前备份旧 PNG。保存已有封面也会备份旧图及封面规格。

新图片追加到现有素材顺序，重复请求不重复添加。页面下方可调整图片顺序。点击「完整图文预览」逐张查看实际保存的封面和配图，连同标题、正文和标签。生成和保存不会修改文案或自动发布。

任务按账号隔离，文案变化会使旧方案过期，旧任务不能覆盖当前稿件。封面保存会检查当前文案、封面规格和封面使用模式，异步刷新不会覆盖正在输入的内容或切换后的页面。原稿快照保存在账号目录的 `cover-jobs/*.input.json`；被替换图片的备份在笔记目录 `cover-backups/`。
