# 选题热点：对标资料到草稿

在「选题热点」选择已采集的对标，点击「生成 3 个有来源的选题」；也可从对标详情进入。选题保留来源链接、观察时间和生成理由，区分采集观察与已完成拆解，未经核实的热度显示待评估。选择一个选题点击「写成笔记」，任务完成后打开文案编辑页。

任务保存冻结输入和阶段结果，经服务端校验后入库。页面显示任务状态、进度与错误，失败可重试。同一选题复用草稿，重复请求不会重复建稿；检测到用户修改时保留修改，不覆盖。服务中断后任务标记失败，可继续重试。旧式已拆解报告与笔记资料也可作为来源。
