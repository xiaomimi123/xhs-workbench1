# M2 内容生产：竞品对标 · 选题 · 文案 · 封面

> 状态：已实现（v0.2.0）。

## 目的

把"找对标 → 拆规律 → 出选题 → 写文案 → 做封面"串成一条流水线：每一步的产出都是文件，下一步直接读取；用户在面板里点按钮，agent 在后台干活，结果实时出现在面板上。

```
竞品对标 ──拆解报告──▶ 知识库（沉淀规律）
    │                      │
    └──根据拆解生成选题──▶ 选题池 ◀── 热点 / 知识库
                              │ 写成笔记
                              ▼
                        文案（meta.json + content.md）
                              │ 做封面
                              ▼
                        封面（cover spec → cover.png）
```

## 数据结构（每个账号独立）

| 模块 | 文件 | 写入方 |
|---|---|---|
| 竞品对标 | `benchmarks/index.json`、`benchmarks/<id>/report.md`、`notes.json`、`screenshots/` | 用户（登记、上传截图）+ agent（拆解） |
| 选题 | `topics/topics.json` | agent（生成、打分）+ 用户（状态、手动添加） |
| 文案 | `notes/<id>/meta.json`、`content.md`、`images/` | agent（写稿）+ 用户（修改） |
| 封面 | `meta.json` 的 `cover` / `coverOptions`，渲染结果 `cover.png` | agent / 用户写规格，工作台渲染 |

字段的完整定义在技能包 `playbooks/` 下的 `benchmark.md`、`topics.md`、`copywriting.md`、`cover.md`，agent 按手册读写，服务端 `server/content.mjs` 读取时做容错（漏写 id 自动补齐、数组/对象两种列表格式都接受）。

## 关键设计与取舍

### 面板按钮 = 预设好的 agent 指令
"让 agent 拆解""写成笔记""生成标题备选"等按钮，本质是带上数据路径和手册名的提示词，直接发进对话。好处：所有 agent 能力都复用对话通道，CLI 模式和收件箱模式都能用；用户在对话里能看到 agent 的过程，也能随时补充要求。需要用户补充细节的（如"改写"）只填进输入框不直接发送。

### 封面：agent 只写规格，工作台负责画
不同 agent 的生图 / 截图能力差异很大，所以封面用 **Canvas 模板**（`web/covers.js`，4 个模板 × 6 套配色，1080×1440）：
- agent 只需要写一段 JSON 规格（模板、配色、文案、强调词），不需要任何绘图能力；
- 工作台检测到规格变化（服务端比较规格哈希与 `.cover-hash`）就在浏览器里自动渲染并保存 `cover.png`；
- 代价：渲染依赖工作台网页开着，网页关闭期间写的规格会在下次打开时补渲染；
- 有生图能力的 agent 可以把图存进 `images/`，用「图片大字」模板做背景。

文字排版：中文逐字断行、英文按词；优先保证用户手动换行的每一行不被拆开；避免最后一行只剩一两个字。

### 违禁词检查：本地词表 + agent 深度检查
`web/lint.js` 提供字数限制和常见风险词（绝对化用语、医疗功效、虚假承诺、站外引流、诱导互动），编辑时实时提示；同一份词表也供 `workbench.mjs lint` 命令和 agent 使用。词表只覆盖常见情况，"让 agent 深度检查"按钮会让 agent 结合知识库的品牌口径再查一遍。

### 并发写入
同一个 JSON 可能被用户和 agent 同时改，采用"最后写入为准"。前端在用户有未保存修改时不会用 agent 的新版本覆盖输入框，只刷新列表；保存后以用户版本为准。

### 信息获取的降级策略
小红书内容通常需要登录才能浏览，agent 能力不同，手册里统一规定降级顺序：控制浏览器 → 网页搜索 → 读用户上传的截图 → 告诉用户需要什么。拿不到的数据留空，禁止编造。

## 用法

1. **竞品对标**：添加对标账号（或让 agent 推荐）→ 上传主页 / 爆款截图（可选）→「让 agent 拆解」→「根据拆解生成选题」/「沉淀到知识库」。
2. **选题热点**：「让 agent 找热点选题」→ 按评分挑选 →「写成笔记」（自动建笔记、关联选题、让 agent 写稿）。
3. **文案**：修改标题 / 正文 / 话题，看实时字数和违禁词提示，「手机预览」看效果。
4. **封面配图**：选模板、配色、改文字，或「让 agent 出 3 个方案」后点选套用 →「保存为封面」。

## 已知限制

- 对标拆解只用模拟数据验证过展示效果，还没用真实 agent 跑完整的拆解流程。
- Claude Code 的 CLI 模式默认放行网页搜索和读取，但不能控制浏览器，所以拆解小红书账号主要靠网页搜索和用户上传的截图。
- 封面渲染依赖系统字体（PingFang / 微软雅黑 / Noto Sans CJK），不同电脑上的字形会略有差异。
