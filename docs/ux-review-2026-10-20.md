# 工作台体验走查记录（2026-10-20）

方式：在浏览器里逐模块打开 v0.6.2 工作台，一次用真实数据目录（已有数据）、一次用全新空数据目录（模拟新用户首次打开）；窗口分别用桌面宽度和 390px 窄屏；统计控制台报错、无名称按钮和控件。未连接真实 agent，未调用任何生图 / 视频 API，未发布任何内容。

## 总体

- 13 个页面（概览、知识库、竞品对标、选题热点、文案、图片创作、视频创作、素材库、发布排期、评论私信、数据复盘、账号管理、连接与设置）全部能打开，控制台没有 JS 报错。
- 390px 窄屏下所有页面没有横向溢出。
- 页面文字最小字号不低于 12px；图片都有 alt；整体没有明显的功能性崩坏。
- 问题集中在三类：**首次使用的连接流程**、**页面信息过载 / 术语**、**空状态与失败提示不够友好**。

## 问题清单（按优先级）

### P0：首次使用必经之路

| # | 位置 | 现象 | 建议 |
|---|---|---|---|
| 1 | 全局（未连接 agent） | 顶栏显示“未连接 agent”，聊天框的发送按钮灰着，唯一的提示是“回到你的 agent，说：运行小红书工作台的连接自检”。网页明明已经能检测本机有哪些 agent，却不让用户在网页里直接选，必须回到 agent 再绕一圈 | 未连接时在概览页和聊天区显示“连接 agent”卡片：列出本机检测到的 agent（含 WorkBuddy 等桌面类），点一下就连接 |
| 2 | 全局（未连接 agent） | 页面里所有“让 agent …”按钮（推荐对标、找热点选题、写正文、深度检查、抓取数据……）都是可点状态，点了只弹一个转瞬即逝的提示，没有可操作的下一步 | 未连接时这些按钮改成引导态（“先连接 agent”并直达连接卡片），或至少让提示停留并带按钮 |
| 3 | 新手引导第 1 步 | 文案是“回到你的 agent 会话说「运行 workbench.mjs bridge-test」重试连接”——对不懂技术的用户是黑话 | 改成“点这里选择要用的 agent”，命令行只放进“高级”折叠里 |
| 4 | 新手引导 | 首次打开直接以弹层盖住整个页面，6 步清单信息量大，“让 agent 帮忙”类按钮在未连接时同样无效 | 弹层只保留前 1–2 步并突出“连接 agent”；其余步骤连通后再展开 |

### P1：信息过载与术语

| # | 位置 | 现象 | 建议 |
|---|---|---|---|
| 5 | 竞品对标（空状态） | 一个空页面上同时出现 8 个操作按钮：补齐缺失的已登记对标、核对登录账号、恢复普通暂停、报告平台限制、确认限制已解除、停止自动访问、启动现有待办…… | 空状态只留“添加对标账号”“让 agent 推荐”；“按需资料采集”区块在有对标账号后再出现，高级操作收进“更多” |
| 6 | 竞品对标 | “报告平台限制 / 确认限制已解除 / 恢复普通暂停”是内部状态机用语 | 改为用户语言（例如“遇到验证码或限制时”），并加一句说明何时需要点 |
| 7 | 图片创作 | 一个页面堆了 4 个入口 + 生图服务 + 成品方式 + 风格 + 候选数量 + 参考图 + 创作记录 + 笔记关联，没有“从哪开始”的引导；APIMart 没配置密钥时只在提交后才发现 | 首屏只露“画面要求 + 生成”，其余折叠为“高级设置”；选 APIMart 但未配密钥时就地提示并链接到设置 |
| 8 | 视频创作 | 即使没有任何参考视频，也显示“实际时长 5.17 秒 · 124 帧 / 24fps”，像是上次测试的残留；五种生成方式（文生 / 首帧 / 参考主体 / v2v / rv2v）术语缩写多 | 没有素材时隐藏该行；方式名带一句话说明，v2v / rv2v 改成“复刻参考视频 / 换成我的产品” |
| 9 | 概览 | 问候语“你好，我的账号”是默认账号名直接拼的，没填账号前很奇怪；4 张快速开始卡片 + 7 步流水线 + 新手引导三处重复导航 | 账号名为默认值时用“你好”；三处入口合并成一个主路径 |
| 10 | 文案编辑器 | 新建笔记后状态标签“草稿”在列表和编辑区重复出现；“让 agent 写正文 / 生成标题备选 / 让 agent 深度检查 / 写视频脚本 / 生成图片 / 删除”平铺一排，删除与写作并列 | 主操作与危险操作分组，删除放到更多菜单 |
