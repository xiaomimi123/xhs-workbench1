# v0.4 增强：多账号登录 · 实况图与多图编辑 · 自动运行 · 备份回收站 · 智能检索 · 自动化测试

> 状态：已实现（v0.4.0，2026-10-15）。

## 1. 多账号分别登录

**问题**：v0.3 只有一份浏览器资料，同一时间只能登一个小红书号，多账号时自动操作会用错号。

**设计**
- 每个工作台账号一份 Playwright 浏览器资料：`browser-profiles/<账号id>/`；MCP 配置按账号生成：`config/mcp/<账号id>.json`。
- `bridge.json` 的参数里用占位符 `--mcp-config {mcpConfig}`，每次调用 agent 时按任务所属账号替换（`server/browser.mjs`、`bridge.mjs`）。
- 同一账号的浏览器资料不能被两个任务同时打开，所以 CLI 模式下**同一账号的任务排队**，不同账号并行。
- **账号核对**（`playbooks/browser.md`）：所有网页操作前读取登录的小红书号，与账号信息里的小红书号比较，不一致立即停止。这条规则对 Claude in Chrome、收件箱模式（共用一个浏览器）同样生效，是最后一道防线。
- agent 登录检查后写 `accounts/<id>/browser.json`，「账号管理」显示登录状态，并提供「在浏览器里登录这个账号」按钮。
- 升级兼容：旧的 `browser-profile/` 自动迁移到默认账号名下，登录状态保留；重新运行 `bridge-test` 不再丢失浏览器配置。

## 2. 实况图（Live 图）笔记 + 多图编辑

**数据**：`meta.json` 的 `media` 数组即发布顺序，每项 `{ file, video? }`；带 `video` 的是实况图（静态图 + 动态视频）。`coverMode` 决定用模板封面还是第一张配图当封面。

**规则**
- `images/` 里新出现的图自动追加到末尾；记录里已不存在的文件自动去掉（`content.mjs` 的 `normalizeMedia`）。
- 同名的静态图和视频自动配对（iPhone 导出的 `IMG_1234.HEIC` + `IMG_1234.MOV`），也可以手动配对 / 取消。
- 支持上传 png / jpg / webp / gif / heic，以及 mov / mp4 视频；HEIC 浏览器无法预览，显示占位。
- 编辑：拖拽或 ← → 按钮排序；按 3:4 / 1:1 / 4:3 / 原比例裁剪（拖动取景、缩放，长边最多 2160 像素）；删除进回收站。实况图不允许裁剪（会和视频对不上）。
- 裁剪生成 `<原名>-crop.jpg`，原图进回收站，可恢复。
- 「下载全部素材」把封面、按序编号的配图 / 实况视频、文案打成 zip，方便手机端手动发布。
- 发布手册：按 `media` 顺序上传；实况图要找网页版的实况图上传入口，**找不到就停止发布**，不降级成普通图片。

> 小红书网页版是否支持上传实况图尚未在真实账号上验证。

## 3. 开机自启与防休眠

- `workbench.mjs autostart on|off`，界面在「连接与设置 → 自动运行」。
  - macOS：`~/Library/LaunchAgents/com.xhs-workbench.agent.plist`（登录时启动、崩溃自动重启、正常停止不重启）。
  - Windows：启动文件夹里的 `xhs-workbench.vbs`（后台启动）。
  - Linux：`systemd --user` 服务。
  - 关闭只删除启动项，不会停掉正在运行的工作台。
- **单实例锁**：启动时发现同一数据目录已有工作台在运行就退出，避免两个调度器重复发布。
- 防休眠三档：不阻止 / 有定时任务时（未来 3 小时有排期、或开了定时检查评论 / 每日抓数据）/ 一直保持。macOS 用 `caffeinate -w`（随工作台退出），Windows 用 `SetThreadExecutionState`，Linux 用 `systemd-inhibit`。只能阻止闲置休眠，合盖休眠无法阻止。

## 4. 备份、导出与回收站

- **回收站索引** `.trash/index.json`：每次删除记录原位置（文件 / 目录）或整条数据（选题、排期、对标等列表条目），界面一键恢复；原位置被占用时加「-恢复」后缀。
- **备份**：`config/ accounts/ knowledge/ chats/` 打成 zip，存到 `backups/`；默认每天自动备份一次、保留 7 份；可下载。不含浏览器登录资料、日志、回收站。
- **恢复**：当前数据先整体移入回收站（可撤销），再写入备份；本机的连接配置（`bridge.json`、`config/mcp/`）保留。
- **导出**：数据复盘页「导出 CSV」（带 BOM，Excel 直接打开）。
- ZIP 读写为零依赖实现（`server/zip.mjs`，UTF-8 文件名，不支持 ZIP64）。

## 5. 知识库智能检索

- 本地检索（`server/search.mjs`）：中文按二字片段、英文按词切分，BM25 打分；标题 ×3、标签 ×2、小标题 ×2；查询中的疑问词 / 虚词（怎么、如何、的……）不参与打分；返回最相关的片段并高亮。
- 「问 agent」：把问题交给 agent 按语义查找并回答、列出引用文档。agent 也可以用 `workbench.mjs kb-search` 先找候选。
- 取舍：不引入向量模型（需要额外依赖或 API Key），用 BM25 + agent 兜底语义理解。

- `npm test`（即 `node --test tests/`），零依赖，约 1 秒跑完 37 个测试。
- 用假 agent（`tests/fixtures/fake-agent.mjs`）模拟纯文本、Claude 流式 JSON、偶发失败、超时、报错等情况，不调用真实 AI。
- 覆盖：Markdown、违禁词、检索、ZIP、知识库与回收站、配图（配对 / 裁剪 / 删除 / 打包）、排期校验与调度器、桥接（解析 / 取消 / 超时 / 重试 / 收件箱 / 按账号排队）、备份恢复、浏览器配置、本地服务集成（令牌、Host 校验、单实例、对话、检索、备份、导出）。
