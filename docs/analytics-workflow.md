# 数据复盘：历史数据 / 对标观察 → 选题 → 新草稿

## 使用

进入「数据复盘」，在上方选择「账号历史 · 本账号历史数据」或「对标观察 · 小互」，点击「生成复盘报告」。报告包含有证据的观察、待验证假设、下一步实验与选题建议；每条观察/建议展示来源标题和观察时间。

「加入选题池」保存一条带报告 ID 与冻结证据的选题，重复点击复用同一选题；「写成新草稿」通过现有写稿任务保存新笔记，可在选题池查看进度并打开草稿。不会自动发布，也不会修改旧笔记。

## 数据与任务边界

- 历史账号业绩和对标公开观察分开。账号复盘冻结笔记累计快照及独立的账号每日数据；总粉丝、每日新增、净增分别标明含义。
- 无效或缺失指标保留未知，真实零保留；汇总展示有数据的样本数。互动率要求阅读大于零且点赞/收藏/评论全部已知。
- 趋势按所选指标的实际来源标注每日新增或累计值；笔记累计合计只显示所有笔记均有数据的日期。单次观察不能推出增长趋势。
- 生成任务冻结输入、保存暂存结果，经服务端校验文字结构和引用 ID 后保存。引用不存在、输入篡改、结果缺失或格式错误均标失败；允许重试，服务重启中断任务明确显示失败。
- 报告按来源和输入版本去重；数据更新后重新生成新报告。完成报告保留生成时的证据，不自动改成新数据。
- 报告的文字结论仍是 Agent 分析，结构校验不等于事实验证或因果验证。复盘不重新访问平台、不保证爆款，也不把未发布草稿赋予虚构的效果数据。
- 选题保留报告 ID、证据 ID、URL 和观察时间；写稿使用冻结证据，不依赖来源后续仍存在。

## 保存位置

账号目录 `analytics/jobs/reviewjob_*.json` 为任务和完成报告；同名 `.input.json` 保存冻结输入、`.result.json` 保存 Agent 暂存结果。选题保存在原选题池，笔记保存到独立新目录。

旧版自由复盘、历史报告和导入数据继续保留；本轮没有新增数据文件解析器或平台采集能力。
