# 发布前检查与排期草案

2026-10-19 已实现并在本地真实工作台验证。入口：文案/封面配图中的「发布前检查」，或发布排期页的检查与草案面板。

## 行为

- 读取当前保存的文案、封面、配图和最新内容检查结果，显示阻断、建议、未核实事项与正文摘要。
- 检查文案非空、长度、词表提示、文件缺失、封面过期、素材顺序和图片数量。计算实际文件 SHA-256；同名替换、重排、文案变化后提交旧检查会被拒绝。
- 当前图像完整性校验支持非交错 PNG，校验块 CRC、压缩像素数据、尺寸及扫描行。其他格式和视频明确阻断，需转换后再检查，不把未验证格式标成通过。本地检查不保证平台审核、事实真实性或素材授权。
- 草案 mode=draft、nonExecuting=true、status=planned，时间固定 Asia/Shanghai。重复提交更新同一活动草案；改期重新校验当前内容。取消保留记录。
- 草案不改笔记状态，不占正式发布额度，到点不通知、不分派任务。即便草案记录的状态误变为 scheduled，调度器仍跳过。通用排期更新接口不能把草案转为自动发布或已发布。
- 正式提醒/自动排期保留在折叠区。草案面板没有创作者中心入口。
- 表单状态按账号保留，异步结果保护账号、当前页面与编辑版本，页面往返后恢复操作按钮。
